Marco M5: apply (aprovação do fechamento de sessão). Abra uma sessão nova, cole a ABERTURA e depois isto.

## Copie a partir daqui

Objetivo: a resposta do prompt de fechamento vira mudanças aplicadas nos arquivos, só depois que eu aprovo cada uma.

Parte 1 — formato:
1. Altere templates/prompts-de-sessao/04-fechar-sessao.md para que a IA, além do texto legível, termine com UM bloco de código cercado por três crases com a etiqueta lore-pack-mudancas, contendo JSON com uma lista de operações. Operações permitidas:
   - estado_adicionar: { secao, linhas[] } — acrescenta linhas ao fim de uma seção do estado.md (secoes pelo título "## ");
   - ficha_criar: { tipo, id, conteudo } — cria fichas/<tipo>/<id>.md; falha se já existir;
   - ficha_adicionar: { id, secao, linhas[] } — acrescenta linhas ao fim de uma seção da ficha (seções pelos títulos em negrito do modelo, como "**Fatos**");
   - ficha_substituir: { id, antigo, novo } — troca um trecho que precisa aparecer exatamente uma vez;
   - alfabeto_adicionar: { linhas[] };
   - nao_aprovado: { itens[] } — só informativo, nunca aplicado.
   Nenhuma operação apaga arquivo. Mostre o texto novo do prompt 04 e espere eu aprovar.
2. Schema Zod das operações.

Parte 2 — núcleo, testes primeiro, tudo puro:
3. extractChanges(textoDaResposta): acha o bloco, valida, devolve operações ou um erro legível (bloco ausente, JSON inválido, operação desconhecida).
4. applyOperation(conteudoAtual, operacao) devolvendo o conteúdo novo, ou erro (seção inexistente, trecho não encontrado ou encontrado mais de uma vez, ficha já existente).
5. preview(operacoes, arquivos): diff por arquivo, sem aplicar nada.
6. Toda operação só pode tocar estado.md, alfabeto.md e fichas/; o id passa pela mesma regra do check (minúsculas e hífen). Bloquear qualquer outro caminho.

Parte 3 — CLI e app:
7. apply <id-da-sessao>: lê sessoes/<id>/fechamento.md, mostra o preview e pergunta operação por operação (aplicar, pular, aplicar todas, cancelar). Depois de aplicar, roda o check e mostra o resultado. Se a pasta for um repositório git, pergunta se quer commitar com mensagem que cita a sessão.
8. No app: na sessão, botão "Fechamento": área para colar a resposta da IA (ou ler o fechamento.md), lista de operações com caixa de seleção e diff de cada uma, botão "Aplicar selecionadas". Depois de aplicar, marca a sessão como fechada.
9. Se o bloco vier inválido, mostrar o erro e um texto pronto para colar de volta na IA pedindo para corrigir só o bloco.

Testes: cada operação em casos de sucesso e de erro; caminho fora da pasta recusado; seção inexistente; trecho repetido; nada é gravado quando eu cancelo.

Critério de aceite: fecho uma sessão real, colo a resposta do prompt 04 no app, aprovo metade das mudanças, e só essas aparecem nas fichas e no estado, com o check passando.

Não faça: operações de apagar, edição livre de arquivo inteiro, aplicar sem confirmação.
